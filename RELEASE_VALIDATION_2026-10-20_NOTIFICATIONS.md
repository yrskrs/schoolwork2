# SchoolNet 4.5.14 — перевірка та оптимізація сповіщень

Перевірено попередні зміни 4.5.11–4.5.13 та коміт `0f2335b`, API доставки,
сторінку `/teacher/settings/?tab=environment&section=notifications` і Docker-сервіси.

Виправлено тест звуку при вимкнених перемикачах, втрату постійних карток при
перезавантаженні, перехід демонстраційних карток до реальних робіт та повторний
показ подій після «Закрити всі». Поля шаблону й мелодії адаптовано для вузьких
екранів. Фонова перевірка налаштувань дотримується серверного інтервалу.

Сторінка сповіщень отримала окремий легкий шаблон та ранню відповідь сервера:
без статистики ШІ, сканування сховища й прихованих вкладок. Форма зберігає
попередні права доступу, CSRF, повідомлення про успіх і перевірку значень.

| Вимірювання на синтетичних даних | Повна сторінка середовища | Сторінка сповіщень |
|---|---:|---:|
| SQL-запити, весь запит Django | 78 | 18 |
| HTML, байти | 695 537 | 88 887 |
| Медіана 5 прогрітих запитів, мс | 46,21 | 11,34 |

Це локальне порівняння SQLite, не навантажувальний тест сервера. API сповіщень
виконує три основні SQL-запити; міграція на інший транспорт зараз не потрібна.
За увімкнених сповіщень видима вкладка опитує сервер раз на 3 секунди,
прихована з дозволеною фоновою доставкою — щонайменше раз на 8 секунд,
вимкнені сповіщення — раз на 30 секунд. Мобільна ОС може обмежувати фоновий звук.

102 серверні тести пройшли. Chrome перевірив збереження, шаблони, мелодії,
таймер, постійні картки після перезавантаження, чергу, відсутність повторного
звуку, ізоляцію класів, навігацію й мобільний вигляд. Окремо пройшли
фонова доставка/звук/заголовок та відновлення застарілої черги після «Закрити всі». Окремо перевірено
`manage.py check`, узгодженість міграцій та `git diff --check`.

Додано міграцію `0068_sync_notification_template_labels`: лише узгодження
підписів choices, без зміни збережених ключів та значень. Django застосовує
її штатним Docker entrypoint разом із collectstatic.

Деталі й команди повторної перевірки: [сповіщення](docs/SUBMISSION_NOTIFICATIONS.md).
