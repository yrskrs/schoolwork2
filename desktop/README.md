# Необов’язкові засоби запуску з ПК

Вебсервери Docker не залежать від цих файлів. Графічне керування збережено для локальної роботи на ПК; залежності Qt залишаються в кореневому requirements.txt. Віртуальне середовище, .env, дані та журнали залишаються в корені проєкту.

- Linux/macOS: `bash desktop/start.sh`, реєстрація: `bash desktop/start_register.sh`.
- Windows: `desktop\start.bat`, реєстрація: `desktop\start_register.bat`. VBS-обгортки запускають ті самі скрипти приховано.
- Запуск не залежить від поточної робочої папки: скрипти визначають корінь проєкту за власним розташуванням.

Старі .desktop-ярлики вилучені: вони містили особистий абсолютний шлях або намагалися перейти командою cd у файл ярлика. Вони не є частиною серверного запуску. Для власного ярлика використовуйте абсолютний шлях до відповідного нового скрипта.
