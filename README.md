# 🐳 Розгортання SchoolNet через Docker (Production)

Ця інструкція описує процес розгортання SchoolNet з використанням Docker та PostgreSQL. Цей підхід забезпечує надійність, портативність і повне збереження даних.

---

## Вимоги

На сервері або новому ПК має бути встановлено:
- **Docker** та **Docker Compose**
- Операційна система: Linux, macOS, або Windows (через WSL2 або Docker Desktop)
- Не потрібно встановлювати Python чи PostgreSQL локально.

---

## 🚀 Перший запуск та Конфігурація

1. **Скопіюйте репозиторій** або розпакуйте архів з проєктом.
2. Створіть файл `.env` на основі `.env.example`:
   ```bash
   cp .env.example .env
   ```
3. Відкрийте `.env` і налаштуйте змінні (змініть паролі!):
   ```env
   APP_PORT=8000
   SECRET_KEY=ваша_унікальна_секретна_строка
   DEBUG=False
   POSTGRES_DB=schoolnet_db
   POSTGRES_USER=schoolnet_user
   POSTGRES_PASSWORD=надійний_пароль
   DATABASE_URL=postgres://schoolnet_user:надійний_пароль@postgres:5432/schoolnet_db
   ```
4. **Міграція бази даних (якщо у вас була стара БД SQLite)**:
   Якщо у вас є старі дані у `schoolnet.sqlite3`, виконайте:
   ```bash
   ./scripts/migrate_db.sh
   ```
5. **Звичайний запуск (якщо це чиста установка)**:
   ```bash
   docker compose up -d
   docker compose exec app python manage.py migrate
   docker compose exec app python manage.py createsuperuser
   ```

Відкрийте браузер за адресою: `http://localhost:8000`

---

## 🔍 Перевірка

Щоб перевірити, чи все працює коректно:
1. **Застосунок**: Відкрийте `http://localhost:8000`.
2. **БД PostgreSQL**: Перевірте логи бази даних: `docker compose logs postgres`.
3. **Volumes**: Переконайтеся, що створені volumes для збереження даних: `docker volume ls` (повинні бути `schoolwork2_postgres_data`, `schoolwork2_app_media` тощо).
4. Завантажте будь-який файл в систему (наприклад, аватарку або завдання), і він буде збережений в `app_media` volume, залишаючись там навіть після видалення контейнера.

---

## 💾 Резервне копіювання (Backup)

Щоб створити резервну копію бази даних (PostgreSQL dump) та всіх завантажених файлів користувачів:
```bash
./scripts/backup.sh
```
Бекап буде збережено у папці `backups/` (наприклад, `backups/2026-08-31_21-00-00/`).

---

## 🔙 Відновлення (Restore)

Щоб відновити систему з попереднього бекапу (УВАГА: це замінить поточні дані):
```bash
./scripts/restore.sh backups/YYYY-MM-DD_HH-MM-SS
```

---

## 🔄 Оновлення системи (Update)

Для безпечного оновлення проєкту (зі збереженням усіх даних):
```bash
./scripts/update.sh
```
Цей скрипт:
1. Автоматично створить бекап.
2. Перезбере Docker-контейнери.
3. Запустить міграції бази даних.
4. Збереже всі ваші медіафайли і БД недоторканими!

---

## ⏪ Відкат (Rollback)

Якщо оновлення пройшло невдало і вам потрібно повернутися до попередньої версії:
1. Зупиніть контейнери: `docker compose stop`
2. Відновіть останній створений бекап (який скрипт `update.sh` створив перед оновленням): 
   ```bash
   ./scripts/restore.sh backups/YYYY-MM-DD_HH-MM-SS
   ```

---

## 🚚 Перенесення на інший комп'ютер

Щоб перенести систему з комп'ютера А на комп'ютер Б, не втративши дані:
1. На **Старому ПК** виконайте бекап: `./scripts/backup.sh`
2. Скопіюйте на **Новий ПК** наступне:
   - Всю папку проєкту (код, `compose.yaml`, `.env`).
   - Папку `backups/` з щойно створеним бекапом.
3. На **Новому ПК** виконайте відновлення:
   ```bash
   # Спочатку зберіть і запустіть порожню інфраструктуру
   docker compose up -d
   
   # Відновіть базу і файли з перенесеного бекапу
   ./scripts/restore.sh backups/YYYY-MM-DD_HH-MM-SS
   ```
4. Готово! Всі користувачі, паролі та файли перенесені.

# 📚 SchoolNet — Локальна шкільна освітня мережа та система перевірки завдань

**SchoolNet** — це сучасний автономний веб-застосунок для організації навчального процесу в локальній шкільній мережі (Wi-Fi або Ethernet). Сервіс дозволяє вчителям публікувати навчальні матеріали, збирати учнівські роботи, автоматично аналізувати та оцінювати їх за стандартами НУШ (Нової української школи) за допомогою штучного інтелекту Google Gemini, вести електронний журнал та переглядати практично будь-які формати файлів безпосередньо у браузері без потреби в інтернеті.

---

## ✨ Ключові можливості

### 🤖 Інтелектуальне ШІ-оцінювання робіт (Google Gemini)
- **Автоматичний педагогічний аналіз робіт учнів** за критеріями НУШ та 12-бальною шкалою.
- **Підтримка груп результатів (ГР 1–4)** відповідно до чинних модельних навчальних програм МОН України.
- **Встановлені пресети критеріїв**:
  - 🌟 Загальне компетентнісне оцінювання НУШ
  - 🌟 НУШ: Інформатична освітня галузь (ГР 1–4)
  - 🌟 НУШ: Математична освітня галузь (ГР 1–3)
  - 🌟 НУШ: Мовно-літературна галузь (ГР 1–4)
  - 📊 Класична / Традиційна система оцінювання (1–12 балів)
- **Завантаження офіційних документів критеріїв** (Word `.docx`, `.pdf`, `.txt`) з автоматичним вилученням структури для ШІ.
- **ШІ-самоперевірка учнем**: можливість учню перед остаточною здачею роботи отримати корисні підказки та рекомендації від ШІ.
- **Вибір конкретних ГР прапорцями** для оцінювання лише профільних результатів конкретної роботи.
- **Підтримка сучасних моделей Gemini** (Gemini 2.5 Flash, Gemini 2.5 Pro тощо) зі збереженням історії та налаштуванням API Key.

### 👁️ Універсальний вбудований переглядач файлів у браузері
Вчитель та учні можуть відкривати та перевіряти будь-які типи робіт прямо в інтерфейсі без сторонніх програм:
- **🗄️ Microsoft Access (`.accdb`, `.mdb`)**: інтерактивний перегляд усіх таблиць бази даних, структури записів та SQL DDL схеми (підтримка як системного `mdbtools`, так і автономного binary-парсера).
- **🐱 Scratch 3 проєкти (`.sb3`)**: інтерактивний запуск Scratch-гри прямо у браузері, видобування спрайтів, звуків, костюмів та перегляд блоків коду.
- **📟 BBC micro:bit (`.hex`)**: розбір Universal Hex, декомпресія MakeCode PXT (LZMA) та перегляд вихідного коду (Blocks, TypeScript, Python).
- **📝 Текстові та офісні документи**:
  - Microsoft Word (`.docx`, `.doc`), RTF
  - Microsoft Excel (`.xlsx`, `.xls`) з переглядом формул та стилів комірок
  - Microsoft PowerPoint (`.pptx`, `.ppt`) у вигляді слайдів
  - OpenDocument (`.odt`, `.ods`, `.odp`)
  - Adobe PDF (`.pdf`) з вбудованим переглядачем
- **💻 Вихідний код та скрипти**: Python (`.py`, `.ipynb`), JavaScript/TypeScript (`.js`, `.ts`, `.tsx`), HTML, CSS, C/C++, C#, Java, Kotlin, Pascal, SQL, Bash/Shell, JSON, YAML тощо з нумерацією рядків та підсвічуванням.
- **🎬 Мультимедіа**: вбудовані відеоплеєр (`.mp4`, `.webm`, `.mov`, `.mkv`, `.avi`, `.3gp`), аудіоплеєр (`.mp3`, `.wav`, `.ogg`, `.flac`, `.aac`) та галерея зображень (`.jpg`, `.png`, `.webp`, `.gif`, `.bmp`, `.svg`).
- **📦 Архіви**: інспекція структури та вихідного коду всередині `.zip`, `.rar`, `.7z`, `.tar`, `.gz`.
- **🔗 Веб-посилання**: вбудований плеєр для YouTube, посилань Google Диск, Google Docs, Vimeo тощо.

### 👥 Інтелектуальне зіставлення імен учнів та антиплагіат
- **Розпізнавання українських імен**: розуміє різний порядок слів (*"Тарас Шевченко"* == *"Шевченко Тарас"*), зменшувальні та пестливі форми (*"Олександр"* == *"Сашко"*, *"Дмитро"* == *"Діма"*, *"Софія"* == *"Соня"*), скорочення (*"Шевченко Т."*) та стійкість до дрібних одруківок у прізвищах.
- **Автоматична прив'язка до канонічного профілю учня** в межах класу в журналі та кабінеті.
- **Пошук дублікатів та плагіату**: автоматичне порівняння SHA-256 хешів та нормалізованого тексту з матеріалами завдання вчителя та роботами інших однокласників.

### 📊 Електронний журнал та аналітика
- Зручний журнал оцінок по класах і предметах.
- Окремий облік та розрахунок середніх балів за групами результатів (ГР 1–4).
- Статуси робіт: *«На перевірці»*, *«Оцінено»*, *«Потребує доопрацювання»*.
- Можливість відправки робіт на повторне доопрацювання з коментарем вчителя.
- Експорт оцінок та звітів у файл Excel (`.xlsx`).
- Імпорт списків учнів з файлів для швидкого наповнення бази.

### 🖥️ Графічні панелі керування (PyQt6)
- **Лаунчер сервера (`launcher.py`)**: запуск, перезапуск, вибір IP/порту, клієнти онлайн у реальному часі, збереження журналів, перемикання світлої/темної теми.
- **Менеджер користувачів (`user_manager.py`)**: створення та адміністрування акаунтів вчителів і адміністраторів, призначення предметів та класів, зміна паролів, експорт списку вчителів.

## 🚀 Швидкий старт

### 🪟 Windows (10 / 11)
1. Переконайтеся, що встановлено **Python 3.10+** (з галочкою `☑ Add Python to PATH`).
2. Двічі клікніть на **`start.vbs`** *(рекомендовано — без мигання консолі)* або **`start.bat`**.
3. При першому запуску автоматично створиться оточення `venv`, встановляться всі бібліотеки з `requirements.txt` та застосуються міграції БД.
4. У вікні лаунчера натисніть **▶ Запустити сервер**.
5. Скопіюйте надане посилання (наприклад, `http://192.168.1.100:8000/`) та поділіться ним з учнями.

> **Реєстрація нових вчителів на Windows:** запустіть **`start_register.vbs`** або **`start_register.bat`**.

---

### 🐧 Linux / 🍏 macOS
1. Відкрийте термінал у папці проєкту та зробіть скрипти виконуваними:
   ```bash
   chmod +x start.sh start_register.sh
   ```
2. Запустіть лаунчер:
   ```bash
   ./start.sh
   ```
3. Для відкриття менеджера користувачів:
   ```bash
   ./start_register.sh
   ```

## 💻 Кросплатформеність (Windows / Linux / macOS)

Сервіс розроблений з повною підтримкою роботи на **Windows** та **Linux/macOS**:
- **Шляхи до файлів**: всі файлові операції використовують кросплатформені модулі `pathlib` та `os.path`.
- **Кодування**: всі операції читання та запису текстових файлів використовують явне кодування `UTF-8` з автоматичним автовизначенням кодувань старих файлів (`CP1251`, `Windows-1251`, `Latin-1`).
- **База даних**: вбудована SQLite3 не потребує встановлення сторонніх СУБД та однаково працює на всіх ОС.
- **Підтримка Access**: парсинг `.accdb`/`.mdb` має вбудований pure-Python Jet fallback, завдяки чому перегляд баз даних працює на Windows «з коробки» без додаткових системних утиліт.
- **Графічний інтерфейс**: PyQt6 нативно інтегрується в стиль інтерфейсу Windows та Linux (включаючи темну тему та підтримку High-DPI екранів).

## 📁 Структура проєкту

```

│   ├── utils.py              # Конвертери офісних файлів у HTML, прев'ю та архіви
│   ├── urls.py               # Маршрутизація URL
│   └── migrations/           # Міграції бази даних
├── schoolnet/                # Конфігурація Django проєкту
│   ├── settings.py           # Налаштування (медіа, статика, безпека, сесії)

│   └── wsgi.py

├── user_manager.py           # Графічне вікно адміністрування користувачів (PyQt6)

├── start_register.bat / .vbs # Запуск менеджера користувачів на Windows
└── start.sh / start_register.sh # Запуск на Linux / macOS
```

## 🔧 Керування через командний рядок (CLI)

```bash
# Активація віртуального середовища
# Linux / macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Запуск веб-сервера
python manage.py runserver 0.0.0.0:8000

# Застосування міграцій бази даних
python manage.py migrate

# Початкове заповнення стандартними предметами, класами, вчителями та адміном:
python seed_data.py

# Створення нового суперкористувача вручну
python manage.py createsuperuser

# Запуск тестів системи
python manage.py test feed
```
