**SchoolNet** — це сучасний автономний веб-сервер та електронний освітній хаб для шкільних локальних мереж (Wi-Fi / Ethernet). Платформа створена спеціально для роботи в умовах українських шкіл: вона повністю автономна (**offline-first**, не залежить від наявності зовнішнього інтернету), оптимізована для розгортання на недорогих міні-серверах (Mini PC, Raspberry Pi, старий ПК чи сервер у кабінеті) та містить передові інструменти оцінювання за стандартами **Нової української школи (НУШ)** за підтримки штучного інтелекту.

## ⚡ Швидкий старт на міні-сервері (3 кроки)

Розгортання на домашньому або шкільному Linux міні-сервері (Ubuntu, Debian, Fedora тощо) займає лічені хвилини:

### 1. Клонуйте репозиторій
```bash
git clone https://github.com/yrskrs/schoolwork2.git
cd schoolwork2
```

### 2. Створіть файл оточення `.env`
```bash
cp .env.example .env
nano .env   # або будь-який інший текстовий редактор
```
> [!TIP]
> У файлі `.env` встановіть надійний `POSTGRES_PASSWORD` та згенеруйте унікальний `SECRET_KEY`. За замовчуванням застосунок працюватиме на порті **8000** (`APP_PORT=8000`).

### 3. Запустіть систему через Docker Compose
```bash
docker compose up -d --build
```
Docker автоматично запустить PostgreSQL 16, проведе всі міграції бази даних, збере статику та підніме веб-сервер Gunicorn.

## 🚀 Майстер першого запуску (First-Run Setup Wizard)

Більше **не потрібно** вручну запускати консольні команди чи створювати суперкористувача через `manage.py createsuperuser`!

1. Відкрийте браузер на будь-якому комп'ютері чи смартфоні в локальній мережі:
   ```
   http://<IP-адреса-сервера>:8000/
   ```
2. Якщо в системі ще немає жодного зареєстрованого користувача, SchoolNet **автоматично перенаправить вас на майстер першого запуску** (`/setup/`):
   - Введіть бажаний логін головного адміністратора (за замовчуванням: `admin`).
   - Вкажіть ПІБ адміністратора або вчителя.
   - Задайте надійний пароль (від 6 символів).
   - Залиште прапорець **«Ініціалізувати базу стандартними предметами та класами НУШ»** активним — система миттєво створить популярні шкільні предмети (*Інформатика, Математика, Фізика...*), класи (*5А–11А*) та базові критерії оцінювання НУШ (ГР 1–4).
3. Натисніть **«Створити адміністратора та увійти»** — ви одразу потрапите в кабінет вчителя з уже налаштованою шкільною структурою!
4. Після цього сторінка `/setup/` буде надійно захищена від повторного доступу сторонніми особами.

## ✨ Ключові можливості системи

### 🤖 Педагогічний ШІ-асистент (Google Gemini та локальна Ollama)
- **✨ ШІ-помічник створення критеріїв оцінювання**: вчитель може звичайними словами описати суть завдання та вимоги, а ШІ за секунди генерує структуровані індивідуальні критерії за 12-бальною шкалою НУШ (початковий, середній, достатній, високий рівні).
- **📝 Індивідуальні критерії оцінювання для кожного завдання**: завдання підтримують специфічні авторські критерії та шкалу балів вчителя, які мають найвищий пріоритет для ШІ при перевірці робіт учнів.
- **Компетентнісне оцінювання НУШ (1–12 балів)**: об'єктивний аналіз робіт учнів у суворій відповідності до навчальних результатів НУШ.
- **Групи результатів (ГР 1–4)**: оцінювання та виставлення окремих балів за галузями МОН (Інформатична, Математична, Мовно-літературна, Природнича тощо).
- **Вибір конкретних ГР прапорцями**: можливість оцінювати в завданнях лише актуальні результати уроку з автоматичним розрахунком середнього балу.
- **🎯 Вибір файлу умови для ШІ («Умова для ШІ»)**: якщо вчитель додає декілька навчальних файлів, він може обрати конкретний файл, який ШІ вважатиме основним еталоном умови та критеріїв оцінювання.
- **📽️ Глибокий аналіз слайдів презентацій (.pptx, .ppt, .odp) та PDF**: ШІ автоматично розбирає структуру слайдів та PDF-сторінок, розпізнає практичні завдання на фінальних слайдах та надійно захищений від помилкового повернення роботи на доопрацювання.
- **🧠 Розумне оцінювання завдань на вибір (варіативні завдання)**:
  - ШІ читає умову вчителя. Якщо вчитель задав роботу з завданнями на вибір (*«виконати будь-яке завдання»*, *«завдання на вибір»* тощо), ШІ спершу аналізує роботу учня та коментар.
  - Якщо учень вказав номер (*«Виконував завдання 2»*) — ШІ оцінює відповідне завдання без жодного штрафу.
  - Якщо учень не вказав номер — ШІ автоматично визначає, яке завдання виконувалось, але **обов'язково додає зауваження** в коментар та знижує оцінку на 1–2 бали за неуважність.
  - Якщо визначити виконане завдання неможливо — робота отримує статус **«Доопрацювати»** із чіткою порадою учневі зазначити номер завдання.
- **🖼️ Мультимодальний аналіз та вилучення зображень**: автоматичне видобування вбудованих зображень і діаграм із баз даних Access (OLE/BLOB), документів Word, PowerPoint та PDF для візуальної перевірки мультимодальними моделями (Gemini).
- **ШІ-самоперевірка учнем**: можливість для учня перевірити роботу перед остаточним надсиланням та отримати конструктивні поради.
- **⚡ Підтримка моделей Google Gemini 3.x Flash та локальної Ollama**: оптимізована робота з моделями Gemini (`gemini-3.6-flash`, `gemini-flash-latest`, `gemini-3-flash-preview`), автоматичний відмовостійкий ланцюжок і запуск відкритих моделей (Llama, Mistral, Gemma, Qwen) безпосередньо на шкільному сервері без інтернету.

### 👁️ Автономний переглядач та аналізатор файлів у браузері
Вчитель та учні можуть переглядати, досліджувати та перевіряти будь-які типи робіт прямо у веб-інтерфейсі:
- **🗄️ Microsoft Access (`.accdb`, `.mdb`) усіх версій**:
  - Повна підтримка сучасних баз даних (ACE 2007–2019) та класичних релізів (Jet 3.x/4.x, Access 97/2000/2003).
  - Інтерактивний перегляд усіх таблиць, схеми полів, типів даних, первинних ключів та індексів.
  - Видобування та підсвічування SQL DDL та SQL-запитів (Queries/Views).
  - Аналіз зв'язків між таблицями (Relationships), форм, звітів та структури макросів.
  - Вилучення графічних об'єктів з OLE-полів та вкладень (Attachments).
  - Перевірка баз даних на плагіат та дублювання.
- **🐱 Scratch 3 проєкти (`.sb3`)**: інтерактивний запуск проєкту прямо у браузері, видобування блоків коду, спрайтів, звуків та костюмів.
- **📟 BBC micro:bit (`.hex`)**: розбір Universal Hex, декомпресія MakeCode PXT (LZMA) та перегляд вихідного коду (Blocks, TypeScript, Python).
- **📝 Офісні документи**: Microsoft Word (`.docx`, `.doc`), Excel (`.xlsx`, `.xls` із рядком формул fx), PowerPoint (`.pptx`, `.ppt`), OpenDocument (`.odt`, `.ods`, `.odp`), Adobe PDF.
- **💻 Вихідний код**: Python (`.py`, `.ipynb`), JavaScript/TypeScript, HTML/CSS, C/C++, C#, Java, Kotlin, Pascal, SQL, Bash тощо з підсвічуванням синтаксису.
- **🎬 Мультимедіа та архіви**: відеоплеєр (`.mp4`, `.webm`, `.mov`), аудіоплеєр (`.mp3`, `.wav`, `.ogg`), галерея зображень та перегляд архівів (`.zip`, `.rar`, `.7z`, `.tar`).

### 📅 Інтерактивний календар та розклад уроків
- **100% узгоджений календар завдань на головній**: алгоритм визначення дат (`get_target_dates`) повністю синхронізує бейджики календаря та стрічку робіт. Натискання на будь-який день у календарі гарантовано відображає заплановані завдання без порожніх сторінок.
- **Огляд на 30 днів**: наочна сітка уроків із підсвічуванням поточного дня, проведених уроків та заміщених занять.
- **Гнучке перенесення уроків**: перенесення уроку в інший день чи час із фіксацією причини в Реєстрі замін.
- **Віджет живого уроку**: динамічний індикатор уроку/перерви у шапці сайту з розрахунком хвилин до дзвінка.

### 👥 Колективні роботи, антиплагіат та автодоповнення
- **Співавторство та групові роботи**: учні можуть вказувати співавторів у файлі або в коментарі. При виставленні оцінки вчителем бали та коментарі автоматично синхронізуються всім співавторам у журнал.
- **Розумне розпізнавання українських імен**: розуміє будь-який порядок слів (*"Тарас Шевченко"* == *"Шевченко Тарас"*), зменшувальні форми (*"Сашко"*, *"Діма"*), скорочення (*"Шевченко Т."*) та стійкість до описок.
- **Природне сортування класів**: класи впорядковані за паралелями: `5А, 6А, 7А, 8А, 9А, 9Б, 10А, 11А`.
- **Детектор плагіату**: автоматичне порівняння SHA-256 хешів та нормалізованого тексту робіт із файлами однокласників.

### 📝 Зручність роботи для вчителів та учнів
- **Для вчителя**:
  - **Режим завдань «Без здачі робіт»**: прапорець «Не вимагає здачі робіт (усне / для опрацювання)» для лекцій, конспектів чи усних відповідей без створення черги здач.
  - **ШІ-помічник критеріїв оцінювання**: генерація критеріїв за розмовним описом вимог вчителя в один клік безпосередньо у формі створення завдання.
  - **Поле індивідуальних критеріїв**: чітке налаштування розбаловки для кожного завдання.
  - **Накопичувальне завантаження файлів з різних папок**: можливість додавати матеріали по черзі без втрати раніше вибраних файлів; кожен файл має картку з розміром та кнопкою видалення.
  - **Позначка умови для ШІ**: легке виділення файлу інструкції перемикачем `🎯 Умова для ШІ`.
  - **Потокова перевірка робіт (File Viewer)**: швидкі клавіші переходу між учнями та роботами без зайвих кліків.
  - **Електронний журнал (Gradebook)**: зведена таблиця успішності з оцінками за датами та групами результатів.
- **Для учня**:
  - **Модальне вікно «Критерії оцінювання»**: перегляд 12-бальної шкали, індивідуальних вимог, актуальних ГР та правил самостійності перед виконанням завдання.
  - **Чітка позначка усних завдань**: замість збиваючих з пантелику кнопок відображається інформативний бейдж «Без здачі — завдання для усного або самостійного опрацювання».
  - **Компактна форма здачі на 1 екран**: оптимізована посадка без потреби гортання вниз.
  - **Прихована за замовчуванням умова**: не перекриває екран і відкривається в один клік кнопкою «Умова завдання» у зручному бічному режимі.
  - **Підказка щодо завдань на вибір**: нагадування вказати номер виконаного завдання або співавторів для збереження максимального балу.
  - **Захисний статус «Доопрацювати»**: якщо ШІ не зрозумів роботу, учень отримує пораду та можливість перездати без негативної оцінки.

## 🛠️ Безпечне обслуговування сервера та оновлення

Усі операції з оновлення, бекапу та відновлення автоматизовані через оптимізовані bash-скрипти в папці `scripts/`.

> [!IMPORTANT]
> **Гарантія збереження даних при оновленні:**  
> База даних PostgreSQL зберігається в Docker Volume `postgres_data`, а завантажені файли завдань та робіт учнів — у Docker Volume `app_media`.  
> Перезбирання контейнера та запуск `scripts/update.sh` **НІКОЛИ НЕ ВИДАЛЯЮТЬ І НЕ СКИДАЮТЬ ЦІ ДАНІ**.

### 🔄 Безпечне оновлення на бойовому сервері (Update)
```bash
./scripts/update.sh
```
1. **Автоматичний бекап**: створює повний зліпок БД та медіа-файлів у `backups/YYYY-MM-DD_HH-MM-SS/` перед будь-якими змінами.
2. **Отримання свіжого коду**: виконує `git fetch` та `git merge`.
3. **Перезбирання контейнера**: оновлює образ `app` без зупинки томів даних.
4. **Очікування готовності БД**: динамічно опитує PostgreSQL через `pg_isready`.
5. **Автоматичні міграції**: запускає `python manage.py migrate --noinput`.
6. **Збір статики**: збирає актуальні стилі та скрипти через `python manage.py collectstatic --noinput`.
7. **Health Check**: перевіряє код відповіді сервера (HTTP 200/302).

### 📦 Створення резервної копії (Backup)
```bash
./scripts/backup.sh
```
- Створює повний бінарний дамп БД PostgreSQL та `.tar.gz` архів каталогу медіа-файлів.
- Монтує том медіа в режимі **`read-only` (`:ro`)** для захисту файлів від пошкодження під час копіювання.
- Перевіряє цілісність дампа і зберігає копію в каталозі `backups/YYYY-MM-DD_HH-MM-SS/`.

---

### ♻️ Відновлення з резервної копії (Restore)
```bash
./scripts/restore.sh backups/2026-09-20_16-00-00
```
*(Для автоматизованого відновлення без підтвердження додайте ключ `--yes`).*

1. Зупиняє сервіс `app` для запобігання новим записам під час відновлення.
2. Безпечно очищає схему `public` та розгортає дамп через `pg_restore`.
3. Очищає та розпаковує файли `media.tar.gz` безпосередньо у Docker-том.
4. Перезапускає сервіс `app` та перевіряє цілісність системи.

## 💻 Локальний запуск без Docker (Windows / Linux)

### Windows (10 / 11)
1. Встановіть **Python 3.10+** (позначте галочку `☑ Add Python to PATH`).
2. Запустіть файл **`start.vbs`** (тихий запуск) або **`start.bat`**.
3. Скрипт налаштує оточення `.venv`, встановить залежності та відкриє лаунчер на базі PyQt6.
4. Для реєстрації додаткових вчителів використовуйте **`start_register.vbs`**.

### Linux / macOS
```bash
chmod +x start.sh start_register.sh
./start.sh
```
