# 🏫 SchoolNet — Автономна шкільна освітня мережа та розумна платформа завдань

[![Python](https://img.shields.io/badge/Python-3.12-blue.svg)](https://www.python.org/)
[![Django](https://img.shields.io/badge/Django-6.0+-green.svg)](https://www.djangoproject.com/)

[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-16-336791.svg)](https://www.postgresql.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)
[![НУШ](https://img.shields.io/badge/НУШ-ГР%201--4-purple.svg)](https://mon.gov.ua/)

**SchoolNet** — це сучасний автономний веб-сервер та електронний освітній хаб для шкільних локальних мереж (Wi-Fi / Ethernet). Платформа створена спеціально для роботи в умовах українських шкіл: вона повністю автономна (**offline-first**, не залежить від наявності зовнішнього інтернету), оптимізована для розгортання на недорогих міні-серверах (Mini PC, Raspberry Pi, старий ПК чи сервер у кабінеті) та містить передові інструменти оцінювання за стандартами **Нової української школи (НУШ)** за підтримки штучного інтелекту.

---

## ⚡ Швидкий старт на міні-сервері (3 кроки)

Розгортання на домашньому або шкільному Linux міні-сервері (Ubuntu, Debian, Fedora тощо) займає лічені хвилини:

### 1. Клонуйте репозиторій
```bash
git clone https://github.com/yrskrs/schoolwork2.git
cd schoolwork2
```

### 2. Створіть файл оточення `.env`
```bash
cp .env.example .env
nano .env   # або будь-який інший текстовий редактор
```
> [!TIP]
> У файлі `.env` встановіть надійний `POSTGRES_PASSWORD` та згенеруйте унікальний `SECRET_KEY`. За замовчуванням застосунок працюватиме на порті **8000** (`APP_PORT=8000`).

### 3. Запустіть систему через Docker Compose
```bash
docker compose up -d --build
```
Docker автоматично запустить PostgreSQL 16, проведе всі міграції бази даних, збере статику та підніме веб-сервер Gunicorn.

## 🚀 Майстер першого запуску (First-Run Setup Wizard)

Більше **не потрібно** вручну запускати консольні команди чи створювати суперкористувача через `manage.py createsuperuser`!

1. Відкрийте браузер на будь-якому комп'ютері чи смартфоні в локальній мережі:
   ```
   http://<IP-адреса-сервера>:8000/
   ```
2. Якщо в системі ще немає жодного зареєстрованого користувача, SchoolNet **автоматично перенаправить вас на майстер першого запуску** (`/setup/`):
   - Введіть бажаний логін головного адміністратора (за замовчуванням: `admin`).
   - Вкажіть ПІБ адміністратора або вчителя.
   - Задайте надійний пароль (від 6 символів).
   - Залиште прапорець **«Ініціалізувати базу стандартними предметами та класами НУШ»** активним — система миттєво створить популярні шкільні предмети (*Інформатика, Математика, Фізика...*), класи (*5А–11А*) та базові критерії оцінювання НУШ (ГР 1–4).
3. Натисніть **«Створити адміністратора та увійти»** — ви одразу потрапите в кабінет вчителя з уже налаштованою шкільною структурою!
4. Після цього сторінка `/setup/` буде надійно захищена від повторного доступу сторонніми особами.

## ✨ Ключові можливості системи

### 🤖 Педагогічний ШІ-асистент (Google Gemini та локальна Ollama)
- **Компетентнісне оцінювання НУШ (1–12 балів)**: об'єктивний аналіз робіт учнів у порівнянні з умовою вчителя.
- **Групи результатів (ГР 1–4)**: окреме оцінювання та виставлення балів за галузями МОН (Інформатична, Математична, Мовно-літературна).
- **Вибір конкретних ГР прапорцями**: можливість оцінювати в завданнях лише потрібні результати уроку з розрахунком точного середнього балу.
- **Підтримка локальних моделей (Ollama)**: можливість запуску відкритих моделей (Llama, Mistral, Gemma, Qwen) безпосередньо на міні-сервері без інтернету.
- **Імпорт офіційних документів критеріїв**: вчитель може завантажити файл критеріїв (`.docx`, `.pdf`) для адаптації оцінювання під свій авторський курс.
- **ШІ-самоперевірка учнем**: кнопка для учня «Перевірити роботу через ШІ» перед здачею, що дає цінні конструктивні підказки.

### 📅 30-денний календар та Реєстр перенесених уроків
- **Огляд на 30 днів**: наочна сітка уроків із підсвічуванням поточного дня, статусу проведених уроків та заміщених занять.
- **Гнучке перенесення уроків**: перенесення уроку в інший день чи час із фіксацією причини та дати.
- **Реєстр замін та перенесень**: окрема таблиця для завуча чи вчителя з інформацією про те, з якої дати на яку перенесено заняття.
- **Віджет живого уроку**: динамічний віджет у кабінеті вчителя, що підказує поточний урок згідно з розкладом дзвінків.

### 👁️ Автономний вбудований переглядач файлів у браузері
Вчитель та учні можуть відкривати та перевіряти будь-які типи робіт прямо в інтерфейсі без сторонніх програм:
- **🗄️ Microsoft Access (`.accdb`, `.mdb`)**: інтерактивний перегляд усіх таблиць бази даних, структури записів та SQL DDL схеми (підтримка як системного `mdbtools`, так і автономного binary-парсера).
- **🐱 Scratch 3 проєкти (`.sb3`)**: інтерактивний запуск Scratch-гри прямо у браузері, видобування спрайтів, звуків, костюмів та перегляд блоків коду.
- **📟 BBC micro:bit (`.hex`)**: розбір Universal Hex, декомпресія MakeCode PXT (LZMA) та перегляд вихідного коду (Blocks, TypeScript, Python).
- **📝 Офісні документи**: Microsoft Word (`.docx`, `.doc`), Excel (`.xlsx`, `.xls`), PowerPoint (`.pptx`, `.ppt`), OpenDocument (`.odt`, `.ods`, `.odp`), Adobe PDF.
- **💻 Вихідний код**: Python (`.py`, `.ipynb`), JS/TS, HTML, CSS, C/C++, C#, Java, Kotlin, Pascal, SQL, Bash тощо з нумерацією рядків та підсвічуванням.
- **🎬 Мультимедіа**: вбудовані відеоплеєр (`.mp4`, `.webm`, `.mov`, `.mkv`), аудіоплеєр (`.mp3`, `.wav`, `.ogg`, `.flac`) та галерея зображень.
- **📦 Архіви**: перегляд списку файлів та розпакування вмісту `.zip`, `.rar`, `.7z`, `.tar`.

### 👥 Інтелектуальне зіставлення імен учнів та антиплагіат
- **Розпізнавання українських імен**: розуміє різний порядок слів (*"Тарас Шевченко"* == *"Шевченко Тарас"*), зменшувальні та пестливі форми (*"Олександр"* == *"Сашко"*, *"Дмитро"* == *"Діма"*), скорочення (*"Шевченко Т."*) та стійкість до одруківок.
- **Природне сортування класів**: класи завжди відсортовані за правилом паралелей: `5А, 6А, 7А, 8А, 9А, 9Б, 10А, 11А` (без стрибків `10А` перед `9А`).
- **Детектор схожості та плагіату**: автоматичне порівняння SHA-256 хешів та нормалізованого тексту робіт із файлами вчителя та однокласників.

### 🎨 Преміальний інтерфейс без блимання
- **View Transitions API**: плавні, безшовні переходи між сторінками сайту без миготіння екрана.
- **Глобальний неоновий індикатор завантаження**: тонка анімована смужка та плаваючий віджет при повільному з'єднанні.
- **Темна та світла теми**: автоматичне підлаштування під системну тему ОС із можливістю ручного перемикання в шапці (налаштування зберігаються в `localStorage`).
- **Зручна 3-колонкова сітка класів**: зручний адаптивний вибір класу в кабінеті здачі робіт для учнів.

## 🛠️ Обслуговування сервера

Усі основні операції автоматизовані через готові bash-скрипти в папці `scripts/`:

### Створення резервної копії (Backup)
Створює повний дамп бази даних PostgreSQL та архів усіх завантажених файлів учнів і завдань:
```bash
./scripts/backup.sh
```
Архів зберігається у папці `backups/YYYY-MM-DD_HH-MM-SS/`.

### Відновлення з бекапу (Restore)
```bash
./scripts/restore.sh backups/2026-09-06_15-00-00
```

### Безпечне оновлення коду (Update)
Скрипт автоматично робить резервну копію, оновлює код, перезбирає контейнери та виконує міграції без втрати даних:
```bash
./scripts/update.sh
```

## 💻 Локальний запуск без Docker (Windows / Linux)

Якщо ви бажаєте запустити систему локально на робочому ПК вчителя:

### Windows (10 / 11)
1. Встановіть **Python 3.10+** (обов'язково позначте галочку `☑ Add Python to PATH`).
2. Запустіть файл **`start.vbs`** (тихий запуск без вікна консолі) або **`start.bat`**.
3. При першому запуску скрипт автоматично створить віртуальне середовище `.venv`, встановить необхідні пакети та відкриє графічний лаунчер сервера на базі PyQt6.
4. Для реєстрації додаткових вчителів використовуйте **`start_register.vbs`**.

### Linux / macOS
```bash
chmod +x start.sh start_register.sh
./start.sh
```

## 📁 Архітектура та структура проєкту

```
schoolwork2/
├── feed/                       # Головний Django-застосунок
│   ├── models.py               # Моделі: Assignment, Submission, Teacher, Subject, ClassGroup...
│   ├── views.py                # Контролери: стрічка, кабінет вчителя, журнал, ШІ-аналіз, setup
│   ├── forms.py                # Форми: FirstRunSetupForm, AssignmentForm, SubmissionForm...
│   ├── middleware.py           # FirstRunSetupMiddleware, OnlineClientsMiddleware
│   ├── urls.py                 # Маршрути застосунку (/setup/, /teacher/, /assignment/...)
│   ├── gemini_service.py       # Інтеграція з Google Gemini API та локальною Ollama
│   ├── access_utils.py         # Автономний парсер Microsoft Access (.accdb, .mdb)
│   ├── scratch_utils.py        # Парсер та браузерний запуск Scratch 3 (.sb3)
│   ├── microbit_utils.py       # Декомпілятор BBC micro:bit (.hex) MakeCode
│   ├── student_matcher.py      # Інтелектуальне зіставлення імен учнів
│   ├── duplicate_detector.py   # Антиплагіат та пошук дублікатів файлів
│   └── tests.py                # Комплексні тести функціоналу системи
├── schoolnet/                  # Системні налаштування Django
│   ├── settings.py             # Конфігурація (DB, Middleware, Static, Media)
│   ├── urls.py                 # Головний роутер
│   └── wsgi.py
├── templates/                  # Шаблони HTML5
│   ├── base.html               # Базовий шаблон (теми, навігація, індикатор завантаження)
│   └── feed/                   # Шаблони сторінок (first_run_setup.html, dashboard, portal...)
├── static/                     # Статичні ресурси (CSS стилі main.css, JS main.js, іконки)
├── scripts/                    # Скрипти бекапу, відновлення, міграції та оновлення
│   ├── backup.sh
│   ├── restore.sh
│   └── update.sh
├── Dockerfile                  # Оптимізований образ з авто-міграціями та збором статики
├── compose.yaml                # Конфігурація сервісів app та postgres:16
├── .env.example                # Шаблон змінних середовища для розгортання
└── launcher.py                 # Графічна панель керування сервером (PyQt6)
```
