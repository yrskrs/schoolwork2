# Прискорення відкриття робіт на перевірку — 04.10.2026

Зміни реалізовані в коді проєкту. Живий сервер `192.168.1.13:8080` не оновлювався; вимірювання виконані на ізольованих синтетичних даних, SQLite у пам'яті та окремому дисковому кеші. Для використання змін на сервері потрібно оновити його застосунок за звичайною процедурою розгортання з README.

Сторінка перевірки одразу показує інструменти. Формування Office-перегляду та перевірка збігів виконуються окремими локальними HTTP-запитами після її відкриття. Це асинхронне підвантаження з браузера, без нової черги worker і без міграцій. Перший перегляд нового складного документа все ще потребує часу на конвертацію, але вона вже не затримує появу інтерфейсу.

Черга отримує лише ID з тими самими фільтрами й сортуванням, а повні дані — лише для сусідніх робіт. Прев'ю Word/презентацій може використовувати окремі картинки замість Base64 усередині HTML. Зображення зберігають оригінальні байти, повтори одного зображення в документі використовують один URL, а браузер завантажує їх поступово. Картинки доступні через перевірку прав учителя, прив'язані до версії конкретного файла і не розміщуються в публічному media. Одночасні підготовка й відкриття одного документа в Linux узгоджуються файловим блокуванням між вебпроцесами.

Наведення або клавіатурний фокус на «Наступна» може підготувати один наступний документ, коли поточний уже готовий. Для слабких пристроїв, неактивної вкладки та економії трафіку підготовка вимкнена. Помилка підвантаження залишає можливість повторити спробу або відкрити повний перегляд. Перевірка збігів до отримання відповіді не позначається як успішна. Перехід назад через кеш браузера поновлює перервані запити.

| Ізольований сценарій | До оптимізації | Після оптимізації |
| --- | ---: | ---: |
| Відкриття сторінки, черга 1000 здач, 100 текстових файлів із теплим кешем | 132,37 мс | 24,46 мс |
| HTML презентації з 20 слайдами та повторюваним зображенням, файл 2,93 МБ | 36 929 341 байт | 11 205 байт + окрема картинка |
| Перше формування HTML цієї презентації | 2421,63 мс | 2014,19 мс, окремим запитом |

Розмір HTML наведено до HTTP-стиснення. Окрема картинка також потребує передавання; таблиця не означає, що весь документ передається за 11 КБ. Ці значення не є гарантією швидкості на виробничому сервері. У новому тестовому прев'ю присутні всі 20 слайдів. Вимірювання формування HTML виконані до додавання файлового блокування; функціональність блокування перевірена окремим тестом одночасного відкриття.

Перевірки:

- 150 пов'язаних тестів: 148 успішних, 2 пропущених. Перевірені фільтри черги, групове оцінювання, ШІ, коментарі, дублікати, повторні здачі, вибір файла, права доступу, відновлення відсутніх картинок та відкат.
- Повний набір: 419 тестів, 410 успішних, 6 пропущених, 3 попередні збої. Нових збоїв після адаптації тестів до підвантаження немає.
- Попередні збої відтворені окремо на чистій копії коміту `59c88dd7bfa3ed9d2af1a5ed497184d369b2cfaf`: `test_11_feedback_and_revision_advice_consistency` (відсутнє поле `strengths`), `test_extract_images_from_xlsx_visual_rendering` (не отримано зображення), `test_ai_recognizes_task_in_teacher_presentation` (не отримано очікуваний PDF-вхід).
- Django `check`: без зауважень; `makemigrations --check --dry-run`: змін немає; `git diff --check`: без зауважень.
- JavaScript перевірений в ізольованому V8 з імітацією DOM та HTTP: завантаження, статуси, повторна спроба, повний перегляд, обмеження підготовки, слабкий пристрій, завершена сесія, переривання та повернення назад. Повний візуальний тест у браузері виробничого сервера не виконувався.

Пов'язані перевірки можна повторити:

```bash
venv/bin/python manage.py test feed.tests_review_performance feed.tests_review_workbench feed.tests_model_review_workspace feed.tests_material_dialog feed.tests_audit_fixes feed.tests_scenarios feed.tests.SchoolNetSubmissionsIntegrationTest --settings=schoolnet.test_settings --noinput
```

Для швидкого відкату підвантаження встановіть `SCHOOLNET_REVIEW_ASYNC=False` у `.env` та перезапустіть вебзастосунок із оновленими змінними середовища. Окремий перегляд можна відкрити з `review_sync=1`; посилання для цього також доступне при помилці підвантаження та без JavaScript. Відкат не потребує зміни БД або учнівських файлів. Місткість спільного кешу налаштовується через `AI_CACHE_MAX_ENTRIES` (типово 2000); за потреби попереднє значення можна повернути до 500.

Приватний `REVIEW_PREVIEW_DIR` типово лежить поруч із `AI_CACHE_DIR` у каталозі `schoolnet-review-previews` і входить до наявного тому `app_cache` у Compose. Картинки старих версій файлів зберігаються на диску до очищення кешу; відсутні картинки поточної версії перегляд відбудує автоматично. Очищення цього приватного кешу не повинно зачіпати том із роботами учнів.
