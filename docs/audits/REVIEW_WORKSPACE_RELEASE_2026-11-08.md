# SchoolNet 4.8.12 — перевірка учнівських робіт

Погоджений після пробної 4.8.11 вигляд стає звичайною сторінкою перевірки. Прибрана позначка пробної версії, узгоджені VERSION, Docker/Compose, README, RELEASES, CHANGELOG і «Що нового» на сайті. Повний перелік змін містить робочу область, спільне збереження оцінки й відгуку, групові оцінки, чернетку ШІ, формули Excel/ODS, кольори читання й мобільне компонування.

## Перевірки

Функціональну перевірку реальних файлів, посилань, формул, тем і мобільного вигляду проведено для 4.8.11: [звіт](REVIEW_WORKSPACE_TRIAL_2026-11-08.md). Для остаточного образу 4.8.12 перед встановленням повторно виконуються всі серверні тести та перевірки оновлювача. Міграцій і нових пакетів немає.

## Встановлення та повернення

Перед перемиканням створюється окрема перевірена резервна копія джерел, вибору образу, Compose-конфігурації та БД. Кандидатний образ не змінює чинні контейнери до успішного завершення перевірок. Тунель, мережі, порти, монтування й сторонні проєкти звіряються з початковим станом. Старі образи очищуються до п’яти зі збереженням потрібних для відкату.

Точні ревізії, результати й каталог резервної копії будуть записані після встановлення. Публікація в GitHub виконується після остаточної перевірки.
