# Навантаження на браузер — 10.11.2026

Перевірка того, скільки роботи сайт дає браузеру: час головного потоку,
довгі задачі, вага ресурсів, фонові опитування, пам'ять. Стенд
`http://127.0.0.1:8010`, Chromium 157 (headless), виміри через
Performance API + CDP `Performance.getMetrics` і `Emulation.setCPUThrottlingRate`.

## Короткий висновок

**Браузер не перевантажений.** У звичайному режимі довгих задач немає,
головний потік у простої зайнятий 7–8 мс на 5 секунд, пам'ять 3–5 МБ.
Єдині помітні витрати — сторінка «Налаштування» (у 5–9 разів важча за інші)
і нестиснена статика в dev-режимі.

HTML 787 → 248 КБ, вузлів 3 003 → 642, довгих задач немає.

## 3. Простий: що відбувається, коли нічого не робити

- Головний потік: **7–8 мс задач на 5 секунд** (0,15 % часу).
- Стилі 0 мс, розкладка 0 мс — фонового перерахунку немає.
- Мережа: **2 запити за 20 секунд** (`/api/teacher/live-status/` і
  `/api/heartbeat/`), тобто опитування раз на 30 с, без «шторму таймерів».
- Прокрутка: 73–86 мс задач на 3 секунди (≈2,5 мс/с), перерахунок стилів
  14–17 мс — легко.
- Пам'ять: **3–5 МБ** JS-купи, DOM 444–3003 вузли.

## 4. Вага ресурсів

У лабораторному режимі (`DEBUG=True`) статика віддається **без стиснення**:

| `main.css` | 128 КБ | 21,6 КБ |
| `school_ui.css` | 43,4 КБ | 7,9 КБ |

| `platform_layout.css` | 21,7 КБ | 4,8 КБ |
| `theme.css` | 11,1 КБ | 3,6 КБ |
| `main.js` | 47,9 КБ | 11,9 КБ |
| `submission_notifications.js` | 21,8 КБ | 5,9 КБ |
| `ai_jobs.js` | 21,7 КБ | 5,5 КБ |
| **Разом на сторінку** | **≈378 КБ** | **≈75 КБ** |

У production (`DEBUG=False`, WhiteNoise `CompressedStaticFilesStorage`) браузер
отримує стиснуті версії; у лабораторії стискається лише HTML
(`PageCompressionMiddleware`), тому 378 КБ — це «найгірший» сценарій.

## 5. Що варто зробити

1. ✅ **«Налаштування» — зроблено.** Вкладки (профіль, середовище, сповіщення,
   ШІ, API) тепер рендеряться на сервері: у HTML лишається тільки активна.
   Результат: **787 → 248 КБ**, **3 003 → 642** вузли, FCP **832 → 176 мс**,
   довгих задач немає. Усередині ШІ так само рендериться одна панель
   (`ai_section`): 691 → 240–420 КБ залежно від розділу.
2. **Ліниве завантаження `ai_jobs.js`** (21,8 КБ) — він потрібен лише на
   сторінках зі ШІ, а підключається в `base.html` для всіх.
3. **Стиснення статики в dev** (увімкнути `WHITENOISE_USE_FINDERS` з
   компресією або тестувати з `DEBUG=False`) — щоб локальні перевірки
   показували реальні 75 КБ, а не 378 КБ.

Критичних проблем немає: сайт не «гріє» процесор, не тримає зайвих таймерів
і не накопичує пам'ять. Усі заміри відтворюються скриптами в
`.local-audits/perf_*.py`.
