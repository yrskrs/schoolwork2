# SchoolNet 4.1.1 — відгуки ШІ та вибір ГР

Дата: 4 жовтня 2026 року. Контрольний коміт перед змінами: `e526b89`. Попередній образ: `schoolwork2-app:checkpoint-before-v4.1.1`.

## План і виконані зміни

1. Перевірити відповідність налаштувань завдання, запиту й відображеного результату.
2. Відновлювати критерії, ГР і режим мислення останньої успішної перевірки вчителя. Показувати групи наступного запиту й попереднього результату. Додати повернення до параметрів завдання для цього класу.
3. Залишити детальну «Перевірку критеріїв» тільки вчителю. Фільтрувати нові й історичні студентські відгуки, polling, пояснення після перезавантаження та коментар при прийнятті оцінки ШІ. Пояснення бала й поради зберегти.
4. Пояснити Temperature як мінливість відповіді, а не суворість оцінювання чи чутливість детектора. У запиті оцінювання передавати точне значення 0 замість підміни на 0.2.
5. Доповнити перевірку походження метаданими ODT/ODP/ODS і вкладеними зображеннями. Звичайний LibreOffice/Collabora не є ознакою ШІ. Відсутність ознак показувати як невідоме походження, без підтвердження самостійності чи непідтвердженого відсотка.
6. Перевірити регресії й дві теми, оновити довідку/README/журнал, створити резервну копію та перезібрати Docker.

## Поведінка перевірки

Раніше після reload переглядач показував ГР із загальних параметрів завдання, хоча попередній запит міг оцінювати інший вибраний набір. Тепер відновлюється фактичний успішний вибір. Порожній/некоректний вибір не запускає запит; якщо модель пропускає обрану групу, показується «Не перевірено», причина й потреба перевірки вчителя. Бал за цю групу не вигадується і не входить до середнього.

Готовий файл не показує процес написання. Нова інструкція забороняє підтверджувати самостійність без доказу; явні твердження про непідтверджене авторство прибираються зі списку сильних сторін нових відповідей. Стиль та змінювані метадані не спричиняють автоматичного штрафу.

До інструкції додано розрізнення виконаного власного аналізу/рішення та загального алгоритму для читача, якщо вправа вимагає власного результату. Персональні дані й імена не вимагаються. Це інструкція моделі, а не гарантія правильного судження в кожній роботі.

## Межі автоматичного визначення ШІ

За готовим текстом без явних слідів походження автоматична перевірка може не виявити генерацію. Відсутність ознак не підтверджує самостійності. Бал характеризує наданий результат; перед прийняттям бала за роботу, де ШІ заборонено, учителю потрібно уточнити процес: пояснення кроків, чернетка або демонстрація. [Обмеження текстових класифікаторів](https://openai.com/index/new-ai-classifier-for-indicating-ai-written-text/).

Temperature не встановлює авторство. Для Gemini 3 [Google рекомендує 1.0](https://ai.google.dev/gemini-api/docs/gemini-3#temperature); нижче значення не гарантує точності.

## Перевірки та розгортання

- 394 Django-тести пройшли у фінальному Docker-образі за 61.465 с, включно з 15 новими сценаріями: приватність критеріїв, історичний polling, метадані OpenDocument, відновлення ГР/шаблону/мислення, порожній вибір, відсутні й дубльовані ГР, точне значення Temperature 0.
- 32 браузерні стани на вигаданих даних: переглядач, налаштування ШІ, результат здачі та деталі здачі; ширина 1600/1280/1024/390 px; світла й темна теми. Переповнення та помилки JavaScript відсутні.
- 7 інтерактивних перевірок: відновлення вибору, повернення ГР завдання, блокування порожнього вибору без API-запиту, передавання обраних кодів, невідоме авторство після AJAX, видимий неперевірений результат, відсутність JS-помилок.
- Python compile, Git whitespace та Bash syntax checks пройшли. Нові міграції не потрібні.
- Повна приватна резервна копія перевірена. Образ 4.1.1 перезібраний, усі три служби healthy. Django system check і перевірка міграцій пройшли; сторінки та статика доступні.
