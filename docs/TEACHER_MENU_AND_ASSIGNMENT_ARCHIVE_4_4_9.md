# Меню профілю та ZIP-архіви завдань — перевірки 4.4.9

Дата: 13 жовтня 2026 року.

## Зміни

- Меню профілю обмежується доступними шириною та висотою viewport, має власне прокручування й адаптується після зміни масштабу тексту. Керування масштабом залишає меню відкритим; Escape закриває його й повертає фокус.
- Замість негайного експорту сьогоднішніх або останніх десяти завдань відкривається сторінка вибору. Доступні дата або період, кілька днів тижня, номер уроку, статус, вибір цілого дня та окремих завдань.
- Дата уроку має пріоритет над публікацією. Для завдань без прив’язки використовується дата відкладеної публікації, публікації або створення. Фільтри дня й номера уроку перевіряють одну й ту саму прив’язку.
- Завдання для кількох класів показується в кожному своєму дні. Позначки синхронізуються, лічильник та експорт враховують його один раз. Зберігаються всі прив’язки завдання.
- Одиночний і груповий експорт використовують спільний формат 1.1. Переносяться тексти, файли, посилання, класи, дати й номери уроків, статуси, час створення та публікації, відкладена публікація й критерії оцінювання.
- Імпорт зіставляє класи за назвою, створює відсутні класи й дзвінки з нового архіву. Валідація, транзакція та очищення записаних файлів запобігають частковому імпорту.
- README, довідка, журнал сайту, CHANGELOG, RELEASES.json, VERSION, Dockerfile та стандартні теги Compose узгоджено з випуском 4.4.9. Міграцій БД не потрібно.

## Перевірки

```bash
venv/bin/python manage.py test \
  feed.tests_assignment_archive \
  feed.tests_ai_assessment_v4 \
  feed.tests_system_logic.SystemAssignmentWorkflowTests \
  --settings=schoolnet.test_settings --verbosity=1

venv/bin/python scripts/test_teacher_archive_ui.py --artifacts /tmp/schoolnet-archive-ui
```

- 40 серверних тестів пройшли локально та в Docker-образі. Використано SQLite у пам’яті й тимчасові файли; робочі дані не використовуються тестами.
- Перевірено відбір за датами, днями тижня й уроками, доступ лише до власних завдань, відсутність неявного експорту, одиночний і груповий формат, перенесення файлів, посилань, класових критеріїв, часових позначок і прив’язок без дати.
- Перевірено створення відсутніх дзвінків, старі архіви, відмову при відсутніх файлах чи некоректних даних, скасування всієї транзакції та очищення записаних матеріалів і документів критеріїв.
- Шість сценаріїв Chrome пройшли: 1366×768 / 100%, 1280×640 / 125%, 1024×600 / 120%, 390×690 / 100%, 360×640 / 125%, 640×360 / 125%; світла й темна теми. Вузькі viewport перевіряються в iframe, щоб обійти мінімальну ширину вікна headless Chrome.
- Перевірено межі меню, доступність пункту виходу після прокручування, зміну масштабу, Escape, вибір цілого дня, спільне завдання в різних днях, точний лічильник, очищення вибору та відсутність горизонтального переповнення карток і помилок JavaScript.
- На запущеному сайті перевірено працездатність app та ai_worker, `manage.py check`, відсутність незастосованих міграцій, HTTP 200 для healthz та нового скрипта вибору ZIP.
- Перед публікацією пройшли ще 26 тестів системних оновлень і навігації налаштувань; окремо звірено номер версії та єдину позначку найновішого випуску в метаданих.

## Межі та використання

Імпорт створює копії у профілі поточного вчителя. Повторний імпорт створить ще один набір копій. Наявні дзвінки зіставляються за номером, загальношкільний час дзвінків не перезаписується. Старий архів без часу відкладеної публікації або даних відсутнього дзвінка потребує уточнення вихідних даних; система повідомляє про це й скасовує імпорт.

Для експорту вівторка: «Експорт завдань (ZIP) → Вівторок → Показати → Обрати всі знайдені → Завантажити ZIP». Для перенесення відкрийте «Імпорт завдань (ZIP)» у профілі вчителя на іншому комп’ютері.
