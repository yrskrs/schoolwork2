# Доробки інтерфейсу й прив’язки уроків — 18.10.2026

## Цілі та критерії приймання

1. «Всі класи» має ті самі зовнішні межі, що й сітка класів під кнопкою.
2. Розклад учителя доступний без відкриття меню профілю. Перемикання теми
   розташоване всередині меню: профілю для вчителя, додаткового меню для учня.
3. Кабінет учителя й налаштування використовують простір під верхньою панеллю
   без зайвих порожніх рядків. Заголовки та дії залишаються доступними.
4. Редактор завдання має рівні картки класів, читабельні поля й компактне
   компонування. Параметри ШІ розташовані в основній колонці перед власними
   критеріями, згорнуті під час початкового відкриття.
5. Нова форма не успадковує класи попереднього завдання. Предмет запам’ятовується.
   Явний перехід із конкретного уроку зберігає його клас, дату й номер.
6. Автоматична прив’язка вибирає поточний або майбутній урок сьогодні, якщо
   він є; поточний урок не переноситься на наступний тиждень. Вибір предмета,
   явного уроку та дати враховується при збереженні.
7. На ширинах від 320 px, у двох темах і з масштабом тексту до 125% немає
   перекриття заголовків, елементів форми й меню.
8. Зміни мають регресійні перевірки, записи в документації та журналі версій,
   окремі коміти й перевірений запущений Docker-образ.
