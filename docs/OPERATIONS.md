# Робота SchoolNet після виправлень

Учні здають роботи без реєстрації та кодів доступу. У відкритому порталі видно кількість актуальних робіт, статуси та коментарі. Числові оцінки вчителя приховані. Перездачі зберігаються в історії й не збільшують підсумок актуальних робіт.

Розмір завантажених файлів не обмежено програмою. Поріг 2 МБ у Django визначає лише перехід з оперативної пам’яті на тимчасовий файл. Завантаження показує прогрес і завершується після підтвердження сервера. Для великих текстових файлів сторінка показує початок тексту; повний файл доступний для завантаження. ZIP-експорти створюються на диску й віддаються потоково.

HTML/SVG/XML залишаються дозволеними файлами роботи, але завантажуються як вкладення з обмежувальними заголовками. Код HTML можна переглянути як текст. Документні HTML-перегляди очищаються від скриптів, обробників подій і небезпечних посилань. Матеріали неопублікованих завдань доступні автору та адміністратору. Архіви оцінок і журнали потребують входу вчителя.

## Черга ШІ

Docker запускає `app`, `ai_worker` і `postgres`. Обробник запускає кожну перевірку в окремому процесі; вебзапит лише створює запис черги. Стан і результат зберігаються в базі. Перезапуск або закриття сторінки не видаляє завдання. Обробник має healthcheck і автоматично перезапускається Docker.

Для учня дозволена одна успішна самоперевірка на завдання. Ліміт спільний між перездачами; одночасні запити використовують один запис черги. Для колективної роботи резервується спроба кожного учасника. Невдала перевірка або тайм-аут звільняє спробу. Ідентифікація використовує наявний запис учня або нормалізоване ім’я і клас, без нової реєстрації.

Самоперевірка використовує умову, матеріали, критерії та налаштування груп результатів конкретного завдання. Резервні моделі беруться зі збереженого списку. Запити до API у тестах замінені контрольованими відповідями: успішні тести підтверджують передачу контексту та поведінку системи, але не гарантують правильність кожного реального висновку ШІ.

`AI_JOBS_EAGER=False` має залишатися для робочого сервісу. `AI_JOB_TIMEOUT` задає час однієї перевірки (600 секунд за замовчуванням). У локальному лаунчері міграції та обробник запускаються автоматично. При ручному запуску потрібні окремі процеси:

```bash
python manage.py migrate
python manage.py runserver
# В іншому терміналі:
python manage.py process_ai_jobs
```

## Перевірка стану та оновлення

```bash
docker compose ps
docker compose logs --tail=80 app ai_worker
# Тести не використовують робочі завантажені файли.
python manage.py test feed --settings=schoolnet.test_settings --noinput
# Тести PostgreSQL запускаються в окремій базі test_schoolnet_audit_20261003.
# Не запускайте два таких набори тестів одночасно.
docker compose run --rm --no-deps -T -e SCHOOLNET_TEST_POSTGRES=1 app \
  python manage.py test feed --settings=schoolnet.test_settings --noinput
```

Тести в наявному образі перевіряють код цього образу. Щоб перевірити ще не зібрані локальні зміни, додайте read-only монтування директорії проекту в `/app`, як у звіті виправлень.

Після успішних перевірок:

```bash
bash scripts/backup.sh
docker compose build app
docker compose up -d app ai_worker
```

Не видаляйте Docker-томи: вони містять базу та учнівські файли. Міграції запускаються при старті `app`, а обробник починає роботу після готовності вебсервісу.

## Резервна копія, відновлення та автоматичне оновлення

Для гарантованого збереження даних реалізовано автоматизовані скрипти у `scripts/`:

1. **Створення резервної копії:**
   ```bash
   bash scripts/backup.sh
   ```
   Скрипт створює узгоджений бінарний дамп PostgreSQL (`database.dump`), архів учнівських медіафайлів (`media.tar.gz`) із прапорцем `--hard-dereference`, фіксує хеші у `SHA256SUMS`, поточний коміт і стан Docker. Усі копії архівуються у захищену теку `backups/`.

2. **Перевірка цілісності та відновлення даних (`scripts/restore.sh`):**
   - **Лише перевірка архіву (безпечний режим, без змін у системі):**
     ```bash
     bash scripts/restore.sh --verify-only backups/schoolnet-backup-YYYY-MM-DD-HHMMSS.tar.gz
     ```
   - **Повне відновлення бази даних та медіафайлів:**
     ```bash
     bash scripts/restore.sh backups/schoolnet-backup-YYYY-MM-DD-HHMMSS.tar.gz
     ```
     Скрипт перевіряє хеші SHA-256, попереджає про перезапис, автоматично зупиняє веб-контейнери, відновлює дамп PostgreSQL через `pg_restore` або в Docker `postgres`, розпаковує медіа та перезапускає сервіси з перевіркою працездатності.

3. **Безпечне оновлення коду (`scripts/update.sh`):**
   ```bash
   bash scripts/update.sh
   ```
   Скрипт автоматично підтягує оновлення з репозиторію GitHub, попередньо обов'язково створює резервну копію через `backup.sh`, запускає міграції бази даних та перезапускає сервіси без простою.
