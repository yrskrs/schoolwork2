# Перевірка SchoolNet 4.4.5 — 12 жовтня 2026

Перевірено schoolwork2: розділ «Оновлення системи», автономну службу updater, агрегацію чейнджлогів, Docker-образи та безпеку відкату.

## Реалізовано

- **Веб-розділ «Оновлення системи»** (`/teacher/updates/`):
  - Доступний виключно суперадміністраторам (`is_superuser` або сесійний `superadmin_mode`).
  - Візуальний степпер етапів: перевірка, підготовка, резервна копія, збірка образу, перезапуск, перевірка здоров'я, завершення.
  - Інтерактивне вікно живого терміналу з автопрокруткою та кольоровою підсвіткою логів.
  - Модальне вікно підтвердження оновлення з попередженням про коротку паузу сервісу.

- **Агрегований показ змін (Changelog Diff)**:
  - Парсинг структурованого `RELEASES.json` (із резервним розбором `CHANGELOG.md`).
  - Фільтрація та групування змін усіх проміжних релізів між поточною версією та цільовою (наприклад, при переході з 4.4.3 до 4.4.5 відображаються релізи 4.4.5 та 4.4.4 з їхніми списками змін).
  - Бейджі типів змін (`feat`, `fix`, `security`, `perf` тощо).

- **Автономна служба оновлення (`updater`)**:
  - Окремий легковиковий контейнер на базі `docker:27-cli` (`scripts/updater_service.py`), що підключається до сокета Docker host.
  - Повна ізоляція: перезапуск контейнерів `app` та `ai_worker` не перериває процес оновлення.
  - Створення резервної копії через `backup.sh` перед оновленням.
  - Перевірка працездатності нового кандидата через `git worktree` та збірку тегованого образу.
  - Автоматичний відкат через `restore.sh` у разі збою збірки або невдачі healthcheck.

- **API та безпека**:
  - Ендпоінти `/teacher/updates/api/check/`, `/start/`, `/status/`, `/rollback/`.
  - Відкритий ендпоінт перевірки здоров'я `/healthz/` (HTTP 200).
  - Захист від повторного або конфліктного запуску кількох процесів оновлення одночасно.

## Результати перевірок

- Django тести: 15/15 тестів `feed.tests_system_updates` успішні (парсинг версій, фільтрація проміжних релізів, контроль прав доступу, обробка мережевих помилок).
- Unit тести updater: 4/4 тестів `scripts/test_updater_service.py` успішні (порівняння версій, fallback парсинг Markdown).
- Docker Compose: валідація конфігурації пройдена успішно, відсутність конфліктів портів хоста.
- Узгодженість версій: `VERSION`, `RELEASES.json`, `CHANGELOG.md`, `feed/changelog.py`, `compose.yaml`, `Dockerfile` оновлено до 4.4.5.
