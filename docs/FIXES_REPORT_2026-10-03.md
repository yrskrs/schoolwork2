# Звіт про виправлення SchoolNet — 03.10.2026

Виконано з урахуванням вимог власника: здача й перегляд робіт без реєстрації та кодів; числові оцінки вчителя приховані; розмір файлів не обмежено; анонімна самоперевірка ШІ доступна один успішний раз для учня на завдання, включно з перездачами.

## Виконані зміни

1. **Повернення до попереднього стану.** Перед змінами створено git-коміт `90d67be`, який включає попередні незакомічені зміни власника. Збережено Docker-образ `schoolwork2-app:checkpoint-90d67be`. Узгоджену копію бази та медіафайлів створено й перевірено в `backups/2026-10-03_16-28-52_XIddHb`. Оновлено скрипт копіювання: процеси запису коротко зупиняються і відновлюються автоматично, перевіряються формати копій і контрольні суми.
2. **Доступ і оцінювання.** Захищено індивідуальну й пакетну перевірку ШІ та застосування оцінки від чужого вчителя. В історії перездач приховано числову оцінку вчителя. Чернетки захищено на сторінках, у перегляді, завантаженні та через `/media/`. Архіви оцінок і журнали не віддаються анонімно. Службове тестування API з власним ключем/URL потребує входу вчителя. Звичайна учнівська самоперевірка залишається анонімною. Числові оцінки перевіряються на діапазон 1–12 перед записом.
3. **Великі файли й збереження.** Віддача файлів потокова, з підтримкою діапазонів байтів. ZIP-експорти створюються на диску. Усі розміри файлів залишаються дозволеними. Gunicorn використовує потоки для тривалих завантажень. Помилка збереження відкочує стан здачі та зберігає попередню актуальну спробу. HTML/SVG/XML завантажуються з обмежувальними заголовками, а документний HTML очищається перед показом. Великі текстові прев’ю показують початок файлу з можливістю завантажити повністю.
4. **Надійність ШІ.** Додано чергу в PostgreSQL та окремий `ai_worker`. Стан і результати переживають перезавантаження сторінки. Повторні й одночасні запити не створюють паралельних перевірок однієї роботи; спроба учня спільна між перездачами та враховує учасників колективної роботи. Збій або тайм-аут не витрачає успішну спробу. Перевірка використовує умову, матеріали, критерії, шаблон і групи результатів завдання. Резервні моделі відповідають збереженим налаштуванням. Учнівські URL перевіряються при переходах і встановленні з’єднання; локальні й приватні адреси заблоковано.
5. **Швидкодія.** Пагінація більше не завантажує всю стрічку; повторно використовуються підготовлені дані розкладу. У контрольному наборі: 32 SQL-запити для 10 завдань і ті самі 32 для 100 завдань. Попередній аудит показував 98 і 278 відповідно. Це контрольний вимір, а не прогноз для всіх фільтрів і реальної історії школи.
6. **Інтерфейс.** Портал показує кількість актуальних зданих, перевірених і очікуваних робіт за фільтрами. Перездачі не збільшують підсумок актуальних робіт. Заголовки й статуси відповідають призначенню порталу. Покращено контраст кольорів, фокус клавіатури та адаптивний підсумок. Додано прогрес завантаження у відсотках/мегабайтах і окреме повідомлення про збереження сервером. Черга ШІ показує збережений статус при поверненні на сторінку.

## Перевірки

- **260 тестів у Docker з PostgreSQL — успішно, без помилок і пропусків.** Використано окрему тестову базу `test_schoolnet_audit_20261003` та тимчасові медіафайли; робочі роботи не підмінялися тестовими.
- Перевірено файл розміром **512 МБ**, потокове завантаження й діапазони байтів, багатофайлові ZIP, приховування оцінок, доступ до чернеток, чужі роботи, HTML-перегляди, критерії завдання, повторні спроби, збої й тайм-аути ШІ.
- Перевірено одночасні запити чотирьох клієнтів та захоплення роботи двома обробниками черги на PostgreSQL.
- Перевірки Django не виявили проблем; незгенерованих міграцій немає. Синтаксис Python і shell-скрипту перевірено.
- Дев’ять основних сторінок формуються успішно; перевірено компіляцію 52 вбудованих JavaScript-блоків та двох нових JS-файлів. Окремо перевірено опитування черги, екранування HTML, очікування серверного підтвердження завантаження та відновлення кнопки після мережевого збою.

Реальні платні API ШІ у тестах не викликалися: використовувалися контрольовані відповіді. Висновки ШІ залишаються рекомендаціями для вчителя. Браузерний ручний огляд і перевірка вигляду на фізичних телефонах у цьому середовищі не виконувалися; візуальні зміни перевірено через шаблони, CSS і формування сторінок. Графічний лаунчер не запускався вручну.

Інструкції обслуговування й повернення: [OPERATIONS.md](OPERATIONS.md).
