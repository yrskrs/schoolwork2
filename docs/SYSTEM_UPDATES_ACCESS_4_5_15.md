# Доступ до сторінки оновлень — 4.5.15

20.10.2026 відновлено видимий перехід до `/teacher/updates/` для вчителів.
Відкрийте меню профілю → **«Оновлення системи»**. Посилання також є в бічному
меню налаштувань і внизу сторінки.

## Чому пункт був відсутній

Сторінка, шаблон і маршрут не видалялися. З часу додавання оновлювача
в коміті `03cec1a` (4.4.5, 12.10.2026) посилання показувалося лише за умовою
`user.is_superuser or is_superadmin_mode`. Сервер також забороняв звичайному
вчителю перегляд сторінки та перевірку випусків. Регресійні тести підтвердили
HTTP 403 до виправлення.

Це пояснює відсутність пункту у вчительському меню на скриншоті. Історія коду
не підтверджує його видалення в останніх випусках і не встановлює, коли або
чому раніше користувач бачив інший набір пунктів.

## Виправлення

- Учитель бачить меню, встановлену версію, опис змін і кнопку перевірки нових
  випусків на GitHub. Перевірка випусків не запускає встановлення.
- Оновлення, перезбірка, відкат і діагностичні журнали доступні адміністратору.
  Вчительська сторінка не запитує статус операції та не опитує адміністративний API.
- Відвідувач без входу та обліковий запис без профілю вчителя не отримують
  доступ до перегляду. Права чинних користувачів не змінювалися.
- Довідка пояснює шлях до сторінки й доступні дії. Версії вебзастосунку,
  оновлювача та Docker узгоджено на 4.5.15; нових міграцій немає.

## Перевірки

- 49 тестів `feed.tests_system_updates`, `feed.tests_platform_layout`,
  `feed.tests_environment_storage` пройшли локально та у фінальному Docker-образі
  без мережі й робочих томів. До виправлення нові перевірки відтворили 403
  сторінки/API та відсутність трьох посилань.
- `scripts/test_updates_ui.cjs`: перевірка версій, успіх, помилки, відкат,
  застарілі статуси; вчительський режим не опитує статус і не запускає операції.
- `scripts/test_settings_ui.py`: п’ять сценаріїв Chrome для адміністратора;
  той самий сценарій додатково виконано зі звичайним учителем у тимчасовій БД.
  Перевірено довідку, обидві теми й вузький екран.
- Окрема браузерна перевірка меню вчителя: кнопка видима та вміщується у вікно
  за фактичних ширин 1440 і 500 px. Знімки зі штучними даними:
  `/tmp/schoolnet-updates-4515-menu/`; один знімок перевірено візуально.
- `manage.py check`, `makemigrations --check --dry-run`, `git diff --check` — OK.

Повторити основні серверні перевірки:

```bash
DJANGO_SETTINGS_MODULE=schoolnet.test_settings venv/bin/python manage.py test \
  feed.tests_system_updates feed.tests_platform_layout \
  feed.tests_environment_storage --noinput
```
