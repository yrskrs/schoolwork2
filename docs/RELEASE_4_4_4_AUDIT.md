# Перевірка SchoolNet 4.4.4 — 11 жовтня 2026

Перевірено лише schoolwork2: стан сервісу, останні коміти, структуру, README та опис оновлень на сайті.

## Виправлення

- ZIP-перенесення завдань втрачало `teacher_ai_instructions`. Поле додано до спільного експорту та імпорту політики ШІ, яким користуються одиночні й масові архіви. Старі архіви без поля підтримуються.
- Запит оцінювання містив ті самі вказівки двічі: окремим приватним блоком та у JSON. Залишено один приватний блок із вимогою не цитувати вказівки учню.
- README скорочено з 377 до 226 рядків: попередні випуски перенесено до [історії](RELEASE_HISTORY.md), повторні інструкції підключення об’єднано, застарілі твердження про поточні версії прибрано.
- В [OPERATIONS.md](OPERATIONS.md) виправлено аргумент `restore.sh`: потрібний каталог копії, а не файл `.tar.gz`. Прибрано помилкову обіцянку оновлення без простою.
- Уточнено опис конфіденційності 4.4.3: поле не виводиться в учнівських шаблонах, а модель отримує заборону цитувати його. Фільтрація старих текстових секцій не гарантує відсутність довільного переказу в кожній відповіді моделі.
- Версії коду, README, Dockerfile, Compose та історії сайту узгоджено на 4.4.4. Нових міграцій немає.

## Перевірки

- До виправлень: 639 Django-тестів, `OK (skipped=2)`.
- Дві регресійні перевірки спочатку підтвердили втрату вказівок у ZIP та їх подвійну появу в запиті.
- Після виправлень: 640 Django-тестів, `OK (skipped=2)`, 91,334 с. Використано код робочої копії, змонтований лише для читання, SQLite у пам’яті та тимчасові медіа.
- 33 перевірки скриптів копіювання/оновлення й протоколу списків: `OK`.
- `makemigrations --check --dry-run`: змін немає; `docker compose config --quiet`, синтаксис Bash та `git diff --check` успішні.
- Дублів версій у журналі оновлень немає; лише поточний випуск має позначку найновішого.

## Робоче середовище

До оновлення `app`, `ai_worker` і `postgres` здорові, головна сторінка повертає HTTP 200, `manage.py check` та `migrate --check` успішні. У переглянутому кінці логів вебсервісу й воркера помилок не знайдено.

Код та опис оновлення 4.4.4 опубліковано в GitHub `main`, коміт `4ac1975`. Робочі контейнери залишаються на образі 4.4.3. `scripts/update.sh` не запускався: автоматична перевірка дозволів відхилила оновлення чинного сервісу без явного погодження короткої зупинки вебсервісу та воркера. Зміни схеми й робочих даних під час цього аудиту не виконувалися. Новий опис у «Оновленнях платформи» з’явиться після розгортання 4.4.4.

Перевірка поведінки зовнішніх ШІ-провайдерів і повторний повний аудит інтеграції трьох сайтів до цієї швидкої перевірки не входять.
