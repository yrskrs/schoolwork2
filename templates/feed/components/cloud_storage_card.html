Публічні файли можна додавати за посиланням. Для приватних файлів підключіть Google OAuth нижче. Пароль Gmail для Drive не потрібний.

Вкажіть посилання на папку із завданнями на Google Drive (переконайтеся, що доступ: «Усі, хто має посилання: Переглядач»).

Ключ API може використовуватися для публічних матеріалів; доступ до приватних файлів надає OAuth.

🔑 Створити API key у Google Cloud ↗
Виберіть або створіть проєкт → «Create credentials» → «API key». У тому самому проєкті увімкніть Google Drive API ↗ та обмежте ключ цим API.
