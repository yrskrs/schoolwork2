🔄 Отримати список учнів з локального журналу прямо зараз

Якщо ваш локальний журнал запущено в мережі або на локальному комп'ютері (наприклад, http://127.0.0.1:8000/api/journal/students або http://localhost:5000/api/roster), введіть його адресу нижче — SchoolNet сам виконає запит і заповнить базу учнями та класами.

📚 Інструкція та документація REST API

Готові приклади запитів для підключення вашого локального журналу
Базовий URL: {{ api_base_url }}
GET /api/v1/journal/grades/

Локальний журнал надсилає цей запит до SchoolNet, щоб отримати виставлені вчителем (або ШІ) оцінки разом з прізвищами, іменами учнів, назвами класів та завданнями.

Параметри фільтрації (Query parameters):
  • class_name=10-А — фільтр по конкретному класу (наприклад 10-А, 9-Б).
  • subject=Інформатика — фільтр по навчальному предмету.
  • since=2026-10-01T00:00:00Z — інкрементальна синхронізація (повертає лише оцінки, виставлені після цієї дати).
  • only_graded=1 — повертати тільки перевірені роботи з оцінкою (за замовчуванням увімкнено).
  • limit=500 — максимальна кількість записів у відповіді (від 1 до 2000).
Приклад cURL запиту:
curl -X GET "{{ api_base_url }}/api/v1/journal/grades/?class_name=10-А" \
  -H "Authorization: Bearer <ВАШ_API_КЛЮЧ>"

POST /api/v1/journal/roster/

Локальний журнал надсилає сюди списки класів та дітей. SchoolNet автоматично створить або оновлює записи без дублікатів. Після цього при здачі робіт учням не потрібно буде вводити свої імена вручну — вони просто обиратимуть своє прізвище зі списку класу!

Формат JSON тіла запиту:
{
  "classes": [
    {
      "name": "10-А",
      "students": [
        {"last_name": "Шевченко", "first_name": "Тарас"},
        {"last_name": "Франко", "first_name": "Іван"}
      ]
    },
    {
      "name": "11-Б",
      "students": [
        {"last_name": "Костенко", "first_name": "Ліна"}
      ]
    }
  ]
}
💡 Альтернативний плоский формат також підтримується: {"students": [{"last_name": "Шевченко", "first_name": "Тарас", "class_name": "10-А"}]}
Приклад cURL запиту:
curl -X POST "{{ api_base_url }}/api/v1/journal/roster/" \
  -H "Authorization: Bearer <ВАШ_API_КЛЮЧ>" \
  -H "Content-Type: application/json" \
  -d '{"classes": [{"name": "10-А", "students": [{"last_name": "Шевченко", "first_name": "Тарас"}]}]}'
GET /api/v1/journal/roster/

Повертає поточну структуру класів та зареєстрованих учнів у платформі SchoolNet. 

curl -X GET "{{ api_base_url }}/api/v1/journal/roster/?class_name=10-А" \
  -H "Authorization: Bearer <ВАШ_API_КЛЮЧ>"
🐍 Приклад для Python (requests) у вашому локальному журналі: 
import requests

API_URL = "{{ api_base_url }}/api/v1/journal"
API_KEY = "sk_journal_ваш_ключ"
HEADERS = {"Authorization": f"Bearer {API_KEY}"}

# 1. Синхронізувати список учнів 10-А класу у SchoolNet:
roster_data = {
    "classes": [
        {
            "name": "10-А",
            "students": [
                {"last_name": "Шевченко", "first_name": "Тарас"},
                {"last_name": "Франко", "first_name": "Іван"}
            ]
        }
    ]
}
r_sync = requests.post(f"{API_URL}/roster/", json=roster_data, headers=HEADERS)
print("Синхронізація списку:", r_sync.json())

# 2. Витягнути оцінки для заповнення локального журналу:
r_grades = requests.get(f"{API_URL}/grades/", params={"class_name": "10-А"}, headers=HEADERS)
grades_data = r_grades.json()
for item in grades_data.get("grades", []):
    student = item["student"]["full_name"]
    grade = item["grade"]
    assignment = item["assignment"]["title"]
    print(f"Учень: {student} | Оцінка: {grade} | Робота: {assignment}")
