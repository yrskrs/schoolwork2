## Результат для вчителя

- Пряме посилання на звичайний файл Drive зберігає справжню назву, тип і вміст. Прибрано спробу експортувати будь-який файл спочатку як Google Документ.
- Справжні Google Docs/Sheets/Slides експортуються у DOCX/XLSX/PPTX; цей режим позначено в списку матеріалів.
- Після «Прикріпити до завдання» внизу діалогу видно прогрес, отриманий обсяг, перевірку та кількість готових файлів. Є скасування імпорту; панель доступна також на низькому екрані та у мобільному вигляді.
- Імпорт працює у серверній черзі. Тимчасові файли приватні, належать конкретному вчителю та не передаються через браузер повторно.
- Розмір, доступна контрольна сума джерела, SHA-256 тимчасової й остаточної копій та структура підтримуваних документів перевіряються до прикріплення. Пошкоджені/неповні файли й сторінки входу відхиляються.
- Нові звичайні завантаження також отримують SHA-256 та звірку після запису у сховище.

Раніше помилково імпортовані матеріали автоматично не замінювалися: для отримання оригіналу їх потрібно додати повторно.

## Google Drive без парсингу

Це можливо: офіційний Drive API з OAuth підтримує приватні файли, метадані й списки папок. Підтримку API/OAuth виправлено, додано пагінацію, перевірку file ID та коректне оновлення токенів. Пароль Gmail не видається за дозвіл Drive.

Публічні файли можна завантажувати за посиланням без OAuth. HTML-парсинг залишено лише як запасний спосіб перегляду публічних папок без налаштованого API, із повідомленням про його обмеження. Для приватних матеріалів потрібне одноразове налаштування OAuth у Google Cloud та згода користувача; приватні параметри в чат передавати не потрібно.

Налаштування й обмеження: [docs/CLOUD_STORAGE.md](docs/CLOUD_STORAGE.md). Офіційні джерела: [дозволи Drive](https://developers.google.com/workspace/drive/api/guides/api-specific-auth), [завантаження й експорт](https://developers.google.com/workspace/drive/api/guides/manage-downloads).
